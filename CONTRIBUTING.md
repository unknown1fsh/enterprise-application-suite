# Katkıda Bulunma Rehberi

Enterprise Application Suite projesine katkıda bulunmak istediğiniz için teşekkürler! 🎉

## Nasıl Katkıda Bulunabilirim?

### 1. Projeyi Fork Edin

GitHub'da projeyi fork edin ve kendi hesabınıza kopyalayın.

### 2. Branch Oluşturun

```bash
git checkout -b feature/amazing-feature
```

### 3. Değişikliklerinizi Yapın

- Kod standartlarına uyun
- Test yazın
- Dokümantasyonu güncelleyin

### 4. Commit Edin

```bash
git commit -m 'Add amazing feature'
```

### 5. Push Edin

```bash
git push origin feature/amazing-feature
```

### 6. Pull Request Oluşturun

GitHub'da Pull Request oluşturun ve değişikliklerinizi açıklayın.

## Kod Standartları

- Java kodları için Google Java Style Guide
- TypeScript/React kodları için ESLint kuralları
- Açıklayıcı değişken ve fonksiyon isimleri
- Yorum satırları ekleyin

## Test Yazma

Yeni özellikler için test yazmayı unutmayın!

## Sorular?

Herhangi bir sorunuz varsa issue açabilirsiniz.

Teşekkürler! 🙏
